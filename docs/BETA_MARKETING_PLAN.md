# Vertriebo Beta Marketing Plan

Stand: 2026-05-29

Dieses Dokument beschreibt Phase F: Beta-Marketing und kontrollierter Start mit 10 bis 50 Beta-Testern.

## Ziel

Vertriebo soll nicht direkt breit beworben werden, sondern kontrolliert mit passenden Beta-Testern starten.

Ziel der Beta:

```txt
Produktfluss validieren
Onboarding testen
Leadqualitaet pruefen
Learning-Loop in echten Organisationen bestaetigen
Pricing und Nutzenversprechen schaerfen
erste Referenzen und Feedback sammeln
```

## Positionierung

Kernpositionierung:

```txt
CRM verwaltet Kontakte. Vertriebo findet Kunden.
```

Erklaerung:

```txt
Klassische CRM-Systeme organisieren bestehende Kontakte.
Vertriebo startet frueher: Es findet passende Firmen, bewertet sie und zeigt, was als Naechstes zu tun ist.
```

Keine falschen Versprechen:

```txt
Kein 100 Prozent DSGVO Claim.
Keine automatischen E-Mails behaupten.
Kein Brevo in Marketingtexten.
Keine garantierten Kunden oder Umsaetze versprechen.
```

## Zielgruppe fuer Beta

Prioritaet 1:

```txt
Gebaeudereinigung
Hausmeisterservice
Maler
Entruempelung
SHK und Heizung
Garten- und Landschaftsbau
Sicherheitsdienst
Bueroservice
```

Prioritaet 2:

```txt
B2B Dienstleister mit lokalem oder regionalem Vertrieb
kleine Teams mit wenig CRM-Struktur
Unternehmen, die bisher Google Suche, Excel oder manuelle Listen nutzen
```

Nicht ideale Beta-Nutzer:

```txt
sehr grosse Konzerne
reine Online-Shops
Privatkunden-Geschaefte ohne B2B-Vertrieb
Nutzer, die vollautomatische E-Mail-Kampagnen erwarten
```

## Beta-Angebot

Vorschlag:

```txt
50 Beta-Plaetze
kostenlos oder stark reduziert fuer begrenzte Zeit
Feedback-Pflicht
frueher Zugang zu neuen Funktionen
```

Moeglicher Text:

```txt
Wir suchen 50 Beta-Tester fuer Vertriebo.
Vertriebo ist eine Vertriebssoftware fuer Dienstleister, die passende Firmen automatisch recherchiert, bewertet und als Tagesliste aufbereitet.
Ideal fuer Unternehmen, die nicht mehr staendig selbst nach neuen Firmen suchen wollen.
```


## Beispieltexte

### Kurzer Hero-Text

```txt
Vertriebo findet Firmen, die zu Ihrem Vertrieb passen.

Statt selbst Google zu durchsuchen, erhalten Dienstleister passende Firmenkontakte, priorisiert und direkt als Tagesliste vorbereitet.
```

### Beta-Text

```txt
Wir oeffnen Vertriebo zuerst fuer 50 Beta-Tester.
Sie testen die automatische Firmenrecherche, CRM-Funktionen und Lead-Bewertung in einer fruehen Version und helfen uns, das System fuer echte Vertriebsarbeit zu schaerfen.
```

### Problem-Text

```txt
Viele Dienstleister verlieren Zeit, weil neue Firmenkontakte manuell gesucht, in Excel gespeichert und spaeter vergessen werden.
Vertriebo verbindet Firmenrecherche, Lead-Bewertung und einfache Nachverfolgung in einem System.
```

### Nutzenpunkte

```txt
Automatische Firmenrecherche
Gebietsabdeckung mit Nachbarorten
Lead-Bewertung aus Recherche-Daten
Einfache Tagesliste fuer den Vertrieb
CRM fuer Kontaktverlauf und Aufgaben
System lernt aus Rueckmeldungen
```

## Demo-Flow

Eine Demo sollte maximal 15 Minuten dauern.

Ablauf:

```txt
1. Kurz Problem abfragen
2. Branche und Region eingeben
3. Automatische Recherche zeigen
4. Leads und Tagesliste zeigen
5. LeadDetail zeigen
6. Feedback/Reason-Code zeigen
7. Learning erklaeren
8. Platform/Support nur intern, nicht fuer Kunden zeigen
9. Naechster Schritt: Beta-Account anlegen
```

## Beta-Onboarding

Nach Eintragung:

```txt
1. Interessent im PlatformAdmin pruefen
2. Status auf kontaktiert setzen
3. Demo oder Kurzgespraech vereinbaren
4. Beta-Account erstellen
5. Onboarding gemeinsam oder per Anleitung durchlaufen
6. Erste Recherche starten
7. Nach 24 bis 48 Stunden Feedback einholen
```

## Feedback-Fragen

Nach erstem Test:

```txt
1. Waren die gefundenen Firmen grundsaetzlich passend?
2. Welche Firmen waren unpassend und warum?
3. Hat die Tagesliste geholfen?
4. Waren die Filter verstaendlich?
5. Was hat gefehlt?
6. Wuerden Sie dafuer zahlen?
7. Welcher Preis waere realistisch?
8. Welche Branche/Zielkunden sollen besser erkannt werden?
```

Wichtige Beta-Kennzahlen:

```txt
Support-Anfragen
Abbruchgruende
```

## Beta-Kriterien

Beta erfolgreich, wenn:

```txt
mindestens 10 echte Organisationen onboarded
mindestens 5 Organisationen starten eine Recherche
mindestens 3 Organisationen bewerten Leads
Learning-Loop verarbeitet echte reason_codes
mehrere Nutzer bestaetigen, dass die Recherche Zeit spart
keine kritischen Security- oder Tenant-Isolation-Fehler auftreten
```

## Was nicht in Beta versprechen

```txt
garantierte Neukunden
garantierter Umsatz
vollautomatischer E-Mail-Vertrieb
perfekte Datenqualitaet
vollstaendige DSGVO-Rechtsgarantie
vollwertiger Ersatz fuer jedes Enterprise CRM
```

## Naechste konkrete Schritte

```txt
1. Landing CTA final auf Beta ausrichten.
2. Waitlist/PlatformAdmin Status-Workflow nutzen.
3. 20 passende Firmen direkt ansprechen.
4. 5 Demo-Termine vereinbaren.
5. 3 echte Beta-Accounts einrichten.
6. Feedback nach 48 Stunden einholen.
7. Nur echte Beta-Probleme fixen.
```

## Merksatz

```txt
Beta ist kein grosser Launch.
Beta ist kontrolliertes Lernen mit echten Nutzern.
```
